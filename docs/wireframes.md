# Wireframes plan

Create low-fidelity wireframes (Figma, draw.io or pen and paper photographed) and save the images in `docs/wireframes/`. Tick each page when its wireframe is done.

| Done | Page | Key elements | Roles |
|------|------|--------------|-------|
| [ ] | Landing | Intro, public verify box, QR scan button | Everyone |
| [ ] | Login / Registration | Role-aware sign-in | Staff |
| [ ] | Dashboard | Recent scans, open alerts, verdict summary | Staff, Auditor |
| [ ] | Product Registry | Create products and batches, issue tags, print QR labels | Manufacturer |
| [ ] | Scan Console | Choose checkpoint, enter or simulate a tag scan | Distributor, Retailer |
| [ ] | Verification Page | Verdict badge, reasons, timeline (list or map) | All |
| [ ] | Alerts Center | Open / acknowledged / resolved, severity filter | Admin, Manufacturer, Auditor |
| [ ] | Analytics | Scan volume, verdicts, alerts by type, checkpoint activity | Staff, Auditor |
| [ ] | Admin Panel | Organizations, users, checkpoints, route policies, keys | Admin |
| [ ] | Reports | Generate and download PDF/CSV audit reports | Admin, Auditor |
| [ ] | Settings | Account, notification preferences, API keys | Staff |

Design rules: works at phone width, verdict colors green (AUTHENTIC), amber (SUSPECT), red (COUNTERFEIT), always show the reasons next to the verdict.
